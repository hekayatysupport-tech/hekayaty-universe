# MASTER FRONTEND PROMPT — HEKAYATY WORLD

Create a premium AAA-quality frontend-only web application called **Hekayaty World**.

This is not a comic store.

This is the official digital hub of a massive Arabic superhero and fantasy universe inspired by the ecosystem approach of Marvel, DC, Star Wars, and League of Legends Universe, but with a completely original identity and design.

The website must be designed as if it already serves millions of users and represents a world-class entertainment franchise.

---

# Core Vision

Hekayaty World is the central destination for:

* Comics
* Characters
* Worlds
* Lore
* Timeline
* News
* Community
* Card Game
* Collections
* Reading Guides
* Universe Encyclopedia

The website should feel cinematic, immersive, premium, modern, futuristic, and highly interactive.

Users should feel they are entering a living universe.

---

# Technical Requirements

Frontend Only.

Do NOT connect any backend.

Do NOT connect any database.

Use realistic mock data.

Use local JSON data and TypeScript interfaces.

Tech Stack:

* React

* React Router
